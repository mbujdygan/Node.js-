# Вимоги до проєкту (System Requirements)

Документ містить перелік бізнес вимог, функціональних та нефункціональних вимог для вебсервісу управління дитячим садком.

---
## 1. Бізнес-вимоги (Business Requirements)
### 1.1. Мета проєкту (Business Goals)
Автоматизувати та цифровізувати адміністративні й навчально-виховні процеси дитячого садка для зменшення операційного навантаження на персонал і підвищення прозорості комунікації з батьками.

### 1.2. Бізнес-потреби та проблеми (Business Needs)
* **Зменшення рутинної паперової роботи**: Відмова від паперових журналів відвідуваності та обліку харчування.
* **Централізація даних**: Єдина база даних для обліку дітей, вихователів, груп та розкладу занять.
* **Прозорість розрахунків**: Автоматичний розрахунок оплати за відвідуваність та харчування.

### 1.3. Ключові показники успіху (KPIs)
* Скорочення часу на ведення щоденного обліку відвідуваності на **70%**.
* Зниження кількості помилок під час розрахунку щомісячної оплати послуг до **0%**.
* Підвищення швидкості інформування батьків про події та стан відвідуваності.
  

---
  
## 2. Технічний стек та середовище
* **Runtime**: Node.js (v18+)
* **Framework**: Express.js
* **Database**: PostgreSQL / MySQL
* **Version Control**: Git / GitHub

---

## 3. Функціональні вимоги (Functional Requirements)

### 3.1. Аутентифікація та авторизація
* **FR-1.1**: Реєстрація та вхід користувачів із використанням JWT-токенів.
* **FR-1.2**: Розмежування прав доступу за ролями (Адміністратор, Вихователь, Батьки).

### 3.2. Управління даними
* **FR-2.1**: CRUD-операції для обліку дітей, груп, персоналу та відвідуваності.
* **FR-2.2**: Валідація вхідних даних API з поверненням коректних HTTP-статусів (`400`, `401`, `404`).
* **FR-2.3**: Ведення журналу аудиту дій (Audit Trail) та збереження історії змін у базі даних.

---

## 4. Нефункціональні вимоги (Non-Functional Requirements)
* **NFR-1.1**: Хешування паролів із використанням `bcrypt`.
* **NFR-1.2**: Час відповіді REST API не повинен перевищувати **300 мс**.
* **NFR-1.3**: Структуроване логування помилок у форматі JSON.
